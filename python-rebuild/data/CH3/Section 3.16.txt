A programmer often needs to find and work with text inside another string. The find()  function is used to find a string or character inside a
string. Ex: Giv en a string s1, s1.find(textToFind) return the index of the first occurr ence of textToFind within s1, or string:npos if not found.
textToFind can be a string or character . string::npos  is a special value representing " no position ".

Getting a substring
A substring  is a contiguous part of a string. Ex: " world" is a substring of "Hello world", but " wrld" is not.
The substr()  function is used to get a substring of a string. Ex: Given a string s1, s1.substr(star tIndex, numcharacters) returns the substring
of s1 starting from index startIndex and having numcharacters characters. When used without the length parameter , s1.substr(star tIndex)
returns the substring of s1 starting from index startIndex to the end of the string.

Inserting and replacing text in a string
A common task after finding text in a string is to inser t new text or replace the found text.

The insert() function inserts text into a string. Ex: s1.inser t(star tIndex, newText) inserts newText into s1 before the character at index
startIndex.
The replace()  function replaces text in a string. Ex: s1.replace(star tIndex, numcharacters, newText) replaces the substring of s1
starting at index startIndex and having numcharacters characters with newText.
