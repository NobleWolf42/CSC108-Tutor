
Detecting ranges using if-elseif-else
A common programming task is to detect if a value lies within a certain range and then perform an action depending on where the value
lies. Ex: If Timmy is less than 6, he can play pee-wee soccer. If Timmy is between 6 and 17, he can play junior league soccer, and if he's
older than 17, he can play professional soccer.
An if-elseif-else structure can detect number ranges with each branch per forming a different action for each range. Each expression only
needs to indicate the upper range part; if execution reaches an expression, the lower range part is implicit from the previous expressions
being false.
