
3.18  Floating-point comparison
Floating-point numbers should not be compared using ==. Ex: A void float1 == float2. Reason: Some floating-point numbers cannot be
exactly represented in the limited a vailable memory bits like 64 bits. Floating-point numbers expected to be equal may be close but not
exactly equal.

  Floating-point comparisons.
Floating-point numbers should be compared for " close enough " rather than exact equality . Ex: If (x - y) < 0.0001, x and y are deemed equal.
Because the difference may be negative, the absolute value is used: fabs(x - y) < 0.0001. fabs() is a function in the math library. The
difference thr eshold indicating that floating-point numbers are equal is often called the epsilon . Epsilon 's value depends on the program's
expected values, but 0.0001 is common.
The std::abs() function is o verloaded to support floating-point and integer types. However, good practice  is to use the fabs() function to mak e
the operation clear .

#include  <iostream>
#include  <cmath>
using  namespace  std;
int  main()  {
   double  bodyTemp ;
   cout  <<  "Enter body temperature in Fahrenheit: " ;
   cin  >>  bodyTemp ;
   if  (fabs(bodyTemp  -  98.6)  <  0.0001)  {
      cout  <<  "Temperature is exactly normal."  <<  endl;
   }
   else  if  (bodyTemp  >  98.6)  {
      cout  <<  "Temperature is above normal."  <<  endl;
   }
