While loop: Basics
A while loop  is a program construct that repeatedly executes a list of sub-statements (known as the loop body ) while the loop 's expression
evaluates to true. Each ex ecution of the loop body is called an iteration . Once entering the loop body , execution continues to the body 's end,
even if the expression would become false midwa y thr ough.
Construct 4.2.1: While loop.
while  (expression )  {  // Loop expression
    // Loop body: Executes if expression evaluated to true 
    // After body, execution jumps back to the "while"
}
// Statements that execute after the expression evaluates to false

Common errors
A common err or is to use the opposite loop expression than desir ed, lik e using x == 0 r ather than x != 0. Programmers should r emember that
the expression describes when the loop should  iterate, not when the loop should terminate.
An infite loop  is a loop that ne ver st ops iter ating. A common err or is to accidentally create an loop, often by for getting to update a
variable in the body , or by creating a loop expression whose e valuation t o false isn 't alwa ys reachable.
