6.28  Functions with 2D array parameters

Arrays of pointers:
Pointers to pointers have a few uses. The most common use is to dynamically allocate an array of pointers:
int **array = new int*[10];
This allocates an array of 10 int pointers which are rows in the above code. It works just like a standard dynamically allocated array, except
the array elements are of type “ pointer to integer ” instead of an integer.

Arrays of pointers:

for(int  count=0;  count<10;  count++)
   array[count]  =  new  int[5];  //these are our columns

We can then access our array as usual,
array[6][4] = 5;
